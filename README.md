# Development of an Application Management of the ENSAH Library

A comprehensive **Library Management System** developed for the ENSA-H library using the C programming language. The application is designed to optimize day-to-day library operations by providing dedicated interfaces for students and administrators.

## Project Overview

This project brings together programming, database management, and user-interface development to deliver a quality, responsive, and scalable library management solution.

The system supports two user profiles:

- **Students**, who can search for books, view availability, and manage borrowing requests.
- **Administrators**, who can manage the collection, oversee circulation, analyze activity, and control student access.

## Key Features

### Authentication and Legal Pages

- Student and administrator login and registration
- Secure, role-based access
- Terms and Conditions page requiring acceptance of library rules before access

### Student Profile

Students can access a dedicated interface with the following features:

- Create an account and log in
- Review and accept the library Terms and Conditions
- Borrow books and track borrowed items
- Search for books by ID
- View the list of currently available books

### Administrator Profile

Administrators have access to a management dashboard that allows them to:

- Add new books to the collection
- Modify book records
- Remove unavailable or outdated materials
- Process returned books
- View statistics and analyze library activity
- Search the book collection efficiently
- Manage borrowed and available books
- Manage the student blacklist and restore access when appropriate

### Blacklist Management

The system includes tools for managing students who violate library policies:

- Add students to the blacklist and restrict their access
- Remove students from the blacklist and reinstate access when appropriate
